# Security Policy

## Supported Versions

Only the latest `main` branch is supported.

| Version | Supported |
|---|---|
| `main` | ✅ |
| Anything older | ❌ |

## Reporting a Vulnerability

If you find a security issue in this repository, **report it privately** —
do not open a public issue.

Use GitHub's private vulnerability reporting:
**https://github.com/bhuvanchandt/bug-bounty-writeups/security/advisories/new**

Expect an acknowledgement within 72 hours and a fix or a reasoned explanation
within 7 days.

## Scope note

This repository contains **sanitized and lab-reconstructed vulnerability
writeups**. It contains no live target URLs, no client data, and no
exploitation material intended for use against systems without authorization.

If you believe a writeup here discloses something that should not be public,
report it privately and it will be reviewed and removed promptly.

## Responsible disclosure expectations

The methodology published here is intended for authorized security testing
only. Per the vulnerability disclosure norms this work follows:

- test only what you own or have explicit written permission to test
- respect the defined scope of any bug bounty program, including exclusions
- report privately, give reasonable remediation time, disclose only after a fix
- do not access data that is not necessary to demonstrate impact
